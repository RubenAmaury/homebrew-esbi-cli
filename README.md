# Homebrew tap for esbi-cli

```bash
brew install rubenamaury/esbi-cli/esbi-cli
sb init
```

[esbi-cli](https://github.com/RubenAmaury/esbi-cli) turns the PDFs, links and emails you save into a Markdown wiki. This tap holds the formula only; each release updates `tag` and `revision` in `Formula/esbi-cli.rb`.
